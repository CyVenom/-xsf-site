xsf performs true DOM-aware reflection analysis: where a payload landed, which characters survived, how hard exploitation really is.

One command, five stages.

A scan is a pipeline. Each stage is independently testable and async.

  1. Crawler

    Follows links, extracts JS endpoints, mines hidden parameters.

  2. Payload engine

    Loads and prioritises payloads by injection context before testing.

  3. Scanner

    aiohttp + a bounded semaphore fire requests concurrently.

  4. Reflection analyzer

    DOM parse, encoding check, false-positive filter.

  5. Reporters

    Console, JSON, HTML or CSV: same findings, four formats.

A reflection is not a vulnerability.

Most scanners stop at the first match. xsf keeps going until it knows the match is exploitable.
